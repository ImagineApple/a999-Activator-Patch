# a999-Activator-Patch
A simple script to patch the a999 Activator in order to continue to downgrade iPhone 6s and 6s+

## How to Use

1. Download [a999 V1.1.0](https://github.com/alex-free/a999activator/releases/tag/v1.1.0) (Note: Do NOT use v1.1.1 or later).
2. Download the latest release of the **a999 Activator Patch**.
3. Open **Terminal** and drag the `a999 Activator Patch.sh` file into the window, then press **Return**.
4. Use the arrow keys to choose **Select a999 Executable**, and select the `a999` file you downloaded in step 1.
5. Choose **Begin Patching**. You may need to enter your account password.
6. Once patching is complete, you can exit the script or start the a999 Activator.

> **Tip:** If you ever want to revert the patches, launch the script again and choose **Revert Patches**.
